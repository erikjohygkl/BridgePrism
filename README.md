# BridgePrism

BridgePrism is a real-time data aggregation engine for scalable network analytics, leveraging auto-scaling clusters.

BridgePrism is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- BridgePrism is a real-time data
- aggregation engine for scalable network
- analytics, leveraging auto-scaling clusters

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/BridgePrism.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

BridgePrism is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
